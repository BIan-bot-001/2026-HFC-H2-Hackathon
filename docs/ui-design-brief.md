# UI Design Brief

- 使用者任務：在活動現場以手機快速找到議程、完成報到、確認座位方向、進入直播、填寫需求回饋及查看交通資訊。
- 資訊架構：全站頁首導覽＋七個獨立頁面；首頁先顯示 DM 預留區，再顯示六張活動導覽卡；手機版使用收合式選單。

## 視覺方向 A：極光流線（推薦並暫定採用）

- 使用淺色 AI 背景圖的藍白光流作為首頁主視覺。
- 白色／霧面半透明圓角卡片，深藍文字，亮藍為主要互動色，金色只作少量重點。
- 動態以 160–240ms 色彩、陰影與位移回饋為主，避免過度動畫。

## 視覺方向 B：智慧方塊

- 大量白底與淡藍區塊，搭配幾何方塊、細線網格與較規律的卡片排列。
- 深色參考圖的藍金元素僅用於圖示與區塊標題，整體更企業化。
- 動態較少，著重資訊掃讀與清楚的區塊層級。

## 暫定色票

| Token | 色彩 | 用途 |
|---|---|---|
| `--color-bg` | `#F5F9FF` | 全站背景 |
| `--color-surface` | `#FFFFFF` | 卡片與內容面 |
| `--color-primary` | `#1267D6` | 主要按鈕與連結 |
| `--color-primary-hover` | `#0B4FA8` | 滑入狀態 |
| `--color-primary-active` | `#083D82` | 按下狀態 |
| `--color-ink` | `#102A43` | 主要文字 |
| `--color-muted` | `#52667A` | 次要文字 |
| `--color-accent` | `#C9952E` | 少量金色重點 |
| `--color-border` | `#D7E5F5` | 邊框與分隔線 |

- 元件：頁首、手機選單、主視覺、DM 預留卡、活動導覽卡、頁面標題、主要／次要按鈕、Forms 嵌入容器、座位圖分段開關、圖片空狀態、交通卡、頁尾。
- 狀態：default、hover、active、focus-visible、disabled、loading、empty、embed-blocked、external-link。
- 響應及無障礙：mobile-first；檢查 375／768／1024／1440px；觸控目標至少 44×44px；文字對比至少 4.5:1；完整鍵盤操作、可見焦點、skip link、圖片替代文字、尊重 `prefers-reduced-motion`。

## 文字線框

### 首頁

```text
┌─────────────────────────────────────────┐
│ Logo        首頁／議程／報到／…   [選單] │
├─────────────────────────────────────────┤
│                                         │
│              DM 圖片預留區               │
│       活動名稱、日期、地點（圖片缺席備援）  │
│                                         │
├─────────────────────────────────────────┤
│ 活動導覽                                 │
│ [議程] [線上報到] [座位圖]               │
│ [交通] [直播連結] [需求回饋]             │
├─────────────────────────────────────────┤
│ 主辦單位／活動資訊                        │
└─────────────────────────────────────────┘
```

### 內容頁共用

```text
┌─────────────────────────────────────────┐
│ Logo／共用導覽                           │
├─────────────────────────────────────────┤
│ 頁面標題＋簡短說明                        │
├─────────────────────────────────────────┤
│ 主要內容卡                               │
│ - 議程：時間軸或圖片                      │
│ - 報到／回饋：iframe＋另開視窗按鈕         │
│ - 座位： [面對舞台｜背對舞台]＋圖片         │
│ - 直播：Teams 開啟按鈕                    │
│ - 交通：地址、方式、地圖連結               │
└─────────────────────────────────────────┘
```
