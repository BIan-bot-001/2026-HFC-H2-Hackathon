# Requirements

- 目標：建立活動當日使用的七頁資訊網站，讓參與者快速取得活動資訊、報到、座位圖、直播、需求回饋與交通資訊。
- 使用者：和潤企業 2026 年 H2 黑客松參與者；使用者以手機瀏覽為主，亦需支援平板與桌面。
- TYPE：主要 TYPE-01 形象展示；次要 TYPE-02 知識圖鑑（結構化活動資訊與媒體）。
- CAP：CAP-01 頁面與導覽、CAP-02 設計系統、CAP-03 內容管理、CAP-16 部署維運。
- Must：七個頁面、RWD、圓角卡片、滑入與按下回饋、鍵盤操作、首頁正式 DM、首頁六項導覽、Excel 議程自動讀取、Forms 內嵌與另開視窗備援、Teams 外部連結、兩張座位圖方向切換、集中式內容設定、Git 版本紀錄、GitHub Pages 部署與活動後取消發布說明。
- Should：減少動態偏好、圖片替代文字、載入失敗提示、404 頁、`noindex`、`robots.txt`、內容更新清單。
- 資料分類：PUBLIC。未知或未經核准的內容一律不公開；座位圖若包含姓名或其他個資，必須重新確認資料分類後才可加入。
- 時程：活動日期為 2026/11/27；實際上線時間待確認。
- 預算：待確認；目前以無付費依賴的靜態方案規劃。
- 成功指標：375px、768px、1024px、1440px 寬度可正常使用；七頁與外部連結可用；主要操作可用鍵盤完成；沒有阻擋級安全或功能缺陷；內容負責人可依文件更新文字、連結與圖片。
- 負責人：網站內容及 GitHub 帳號負責人為使用者；技術建置由 Codex 協作，正式部署須另取得 G4 核准。
- 已知限制：一般 GitHub Pages 為公開網站；`noindex` 與未公開網址不是存取控制。Microsoft Forms 是否允許 iframe 受表單與公司政策影響，因此必須提供另開視窗備援。面對舞台座位圖尚待提供。
