# Threat Model

- 資產：公開活動內容、DM、議程、交通資訊、座位圖、Forms／Teams 外部網址、網站原始碼與部署設定。
- 信任邊界：使用者瀏覽器、GitHub Pages、Microsoft Forms、Microsoft Teams、外部地圖服務。
- 資料流：瀏覽器從 GitHub Pages 讀取靜態內容；使用者主動前往或嵌入載入 Microsoft 服務；網站不接收或保存表單答案。
- 攻擊者：公開網際網路使用者、取得轉傳連結者、嘗試竄改外部網址或提交惡意內容者。
- 威脅：誤把未核准資訊公開、連結被轉傳、釣魚或錯誤外部網址、iframe 限制導致功能失效、圖片中含個資、供應鏈或秘密誤入版本庫、網站活動後未下架。
- 嚴重度：目前為中低風險公開靜態網站；若座位圖含個資或需真正限制存取，風險提升並需重新評估架構。
- 控制：公開內容白名單、集中式連結設定、所有外部連結標示網域並使用 HTTPS、Forms 另開視窗備援、秘密與敏感字串掃描、圖片人工複核、`noindex` 與 `robots.txt` 降低索引、活動後取消發布 runbook、G4 部署核准。
- 殘餘風險：公開網址可被轉傳、截圖或保存；`noindex` 不保證不被發現；外部 Microsoft 服務可用性與公司登入政策不由本網站控制。
- 責任人：網站內容與發布負責人為使用者；正式座位圖與外部連結須由使用者核准。

## 資料欄位分類

| 欄位 | 分類 | 是否發布 | 備註 |
|---|---|---:|---|
| 活動名稱、日期、地點、主辦單位 | PUBLIC | 是 | 已由使用者提供 |
| DM、議程、交通資訊 | PUBLIC | 待提供後發布 | 發布前人工檢查 |
| Forms／Teams URL | PUBLIC | 待提供後發布 | URL 本身不可視為秘密 |
| 座位圖 | PUBLIC 或待重分類 | 待確認 | 若含姓名／員編／部門等資料需重新核准 |
| 表單回覆 | 不由本站處理 | 否 | 由 Microsoft 服務處理 |
